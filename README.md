# 预演台 · 官网 + 在线演示

两个页面，一个目录，纯静态：

- `index.html` —— 产品介绍页（Apple 式排版）：大标题、深色 / 浅色交替、居中构图，逐节介绍 AI 导演、场景、机位、镜头、运镜、角色、导出、规格。每一节里的三维画面、俯视图、姿势、运镜都是真的能操作的。
- `demo.html` —— 完整在线演示：左侧对话 + 右侧实时三维，能手动拖对象、改属性、记镜头、按时间轴播放、导出分镜表。

## index.html 里能玩什么

| 区块 | 交互 |
|---|---|
| 首屏 | 视口缓慢自转；底部五个镜头缩略图实时渲染 |
| AI 导演 | 点下面三句话，家具 / 人物 / 机位一件件落进右边的房间 |
| 场景 | 白模客厅，可拖动旋转 |
| 机位 | 俯视图里点机位，扇形视野换色；下方图例同步 |
| 镜头 | 往下滚，画面在五个机位之间硬切，底部卡片跟着亮 |
| 运镜 | 八个按钮，机位真的推、拉、摇、移 |
| 角色 | 八个姿势，SVG 骨架当场变形 |
| 导出 | 「试一下渲染」跑一条进度 |

## 结构

```
index.html              介绍页
demo.html               完整演示
assets/css/landing.css  介绍页样式
assets/css/app.css      演示页样式
assets/js/engine.js     三维引擎：画家算法、透视投影、拾取、姿势骨骼、缩略图
assets/js/landing.js    介绍页交互（各区块挂载、滚动切镜、AI 小演示）
assets/js/app.js        演示页：本地规则 AI 导演、镜头轨、播放、导出、抽屉
assets/vendor/          GSAP（只用于演示页的消息入场）
assets/img/             favicon、分享图
assets/download/        v0.21 便携版压缩包
```

## 设计取舍

- 字体用系统字体栈（Windows 上是 Segoe UI + 思源黑体），不联网加载字体，打开即定稿。
- 深色用 `#000`，浅色用 Apple 的 `#f5f5f7`；强调色只有一个琥珀色 `#f0a13a`，和软件里的机位高亮同色。
- 导航是 48px 的毛玻璃条，深色常驻，跨深浅两色区块时不变色——和 apple.com 的做法一致。
- 没有引入任何 UI 框架；滚动切镜是手写的 `scroll` 监听，不用插件。

## 打开

双击 `index.html` 即可，`file://` 下所有相对路径都成立。想用服务器：

```powershell
python -m http.server 8000 --directory .
```

## 说明

网页版的「AI 导演」是本地规则解析，不连模型；桌面版才接真的聊天模型。页面上的三维画面全部是实时 canvas 绘制，不是软件截图。
